Markdown 是写博客最实用的格式。语法简单，任何文本编辑器都能打开。

## 基础语法

```markdown
# 一级标题
## 二级标题
### 三级标题

**粗体** 和 *斜体*

- 无序列表项
1. 有序列表项

[链接文字](https://example.com)

![图片描述](image.jpg)

> 引用文字

`行内代码`

```
代码块
```
```

## 进阶技巧

### 表格

| 列1 | 列2 | 列3 |
|-----|-----|-----|
| A   | B   | C   |

### 任务列表

- [x] 已完成的事项
- [ ] 待办事项

### 脚注

这是一段带脚注的文字[^1]

[^1]: 脚注内容在这里

### 数学公式（需要渲染支持）

$$E = mc^2$$

## 推荐编辑器

| 编辑器 | 特点 |
|--------|------|
| Typora | 所见即所得，体验最好 |
| VS Code | 免费 + 插件丰富 |
| Obsidian | 双链笔记，适合知识管理 |
| Notion | 团队协作友好 |

Markdown 的核心理念是**内容优先、格式从简**。把精力放在写什么上，而不是怎么排版。
