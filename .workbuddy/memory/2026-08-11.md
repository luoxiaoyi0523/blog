## 搭建个人博客（Astro 5 + Giscus + GitHub Pages）
- 技术栈：Astro 5 静态站点 + Giscus 评论（GitHub Discussions，免后端）+ GitHub Pages 部署。
- 文章 = `src/content/blog/*.md`（frontmatter: title/description/pubDate/category/tags/draft）。
- 关键文件：`src/content.config.ts`（glob loader + zod schema）、`src/consts.ts`（站点信息 + Giscus 配置）、`src/pages/*`（首页分页、blog/[slug]、categories/*、tags/*、about、404、rss.xml.js）、`src/components/*`、`src/layouts/*`、`src/styles/global.css`。
- 安装/构建用托管 Node 22：`C:\Users\Hkyuban\.workbuddy\binaries\node\versions\22.22.2\npm.cmd`。
- 运行：`npm run dev`（本地预览 4321）/ `npm run build`（产物 dist/）。
- 注意：npm 安装与构建时出现的 `[safe-delete] 操作失败` 是本沙箱 trash-shim 的误报，不影响产物。
- 启用评论需手动：建 GitHub 仓库、开 Discussions、装 Giscus App，把 repo/repoId/categoryId 填回 `src/consts.ts` 的 `GISCUS`。
- 部署：`.github/workflows/deploy.yml` 已就绪，push 到 main 即可（仓库需在 Settings→Pages 选 GitHub Actions 源；个人页在 astro.config.mjs 设 site，项目页额外设 base）。
