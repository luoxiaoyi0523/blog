# 把你的摄影作品放在这个文件夹里

## 怎么添加一张照片
1. 把图片文件（`.jpg` / `.png` / `.webp` / `.gif` / `.avif`）复制进这个 `photos` 文件夹。
2. 文件名就是它的说明文字 —— 例如 `海边日落.jpg` 会显示为「海边日落」。
   - 用 `-` 或 `_` 分隔的词会自动变成空格，例如 `2026-东京塔.jpg` → 「2026 东京塔」。
3. 提交并推送代码（或直接在 GitHub 网页上传文件），网站会自动重新部署，
   新照片就出现在「摄影」页面，点击可放大查看。

## 注意
- 这个 `README.md` 只是说明，不会被当成照片展示。
- 图片会由 Astro 自动压缩优化，原图多大都没关系，但单张别超过几十 MB 以免构建太慢。
- 想删照片：把这个文件夹里对应的文件删掉，重新提交推送即可。
